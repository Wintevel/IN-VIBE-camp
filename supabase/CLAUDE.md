# supabase 작업 규칙

담당: 백엔드(팀원). 루트 `CLAUDE.md` 의 공통 규칙을 먼저 따릅니다. 이 폴더의 내용과 방식은 백엔드 담당이 정합니다.

- 수정 범위는 `supabase/` 입니다. `frontend/` 는 읽기만 하고 수정하지 않습니다.
- 스키마 변경은 `migrations/` 의 SQL 파일로 남기고, 바꾼 내용은 같은 PR에서 `docs/api.md` 에 반영합니다. 프론트가 쓰는 테이블·컬럼·RPC 이름을 바꿀 때는 프론트 담당(한재준)을 리뷰어로 지정합니다.
- 모든 테이블에 RLS 를 켭니다. 하루 3개 상한, 위치 반경, 사진 해시 중복 같은 악용 방지 판정은 DB 함수(`approve_claim` 등)에서 서버가 최종 결정합니다. 규칙 내용은 `docs/api.md` "악용 방지 규칙" 을 따릅니다.
- `service_role` 키와 DB 비밀번호는 커밋하지 않습니다.
