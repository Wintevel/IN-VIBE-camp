# web 작업 규칙

담당: 미정. 정해지면 이 줄과 루트 `CLAUDE.md` 표를 고칩니다. 루트 `CLAUDE.md` 의 공통 규칙을 먼저 따릅니다.

- 수정 범위는 `web/` 입니다. `frontend/`(앱)·`supabase/` 는 읽기만 하고 수정하지 않습니다.
- 앱과 같은 Supabase 를 `supabase-js` 로 씁니다. 브라우저에는 anon key 만 두고 `service_role` 키는 절대 넣지 않습니다.
- 제휴사 권한은 로그인한 제휴사 계정 + Supabase RLS 로 제한합니다(자기 의뢰만 생성·조회·수정). 스키마·정책 변경이 필요하면 `docs/api.md` 에 요청으로 적고 백엔드 담당이 처리합니다.
- 담당자가 정해지기 전에는 스캐폴드를 만들지 않습니다.
