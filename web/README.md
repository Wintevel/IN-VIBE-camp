# 집게표 파트너 (제휴업체용 웹)

제휴업체·기관이 환경 미화 의뢰를 올리고 결과를 보는 웹입니다. `web/.env`(`.env.example` 참고)에 Supabase 주소와 anon key 가 있으면 서버에 연결되어 이메일 로그인 뒤에 쓰고, 없으면 시연용으로 브라우저 저장소에만 남습니다.

- 실행: `npm install` 후 `npm run dev`
- 빌드: `npm run build` (결과는 `dist/`)
- 배포: `main` 에 합쳐지면 앱 웹 미리보기와 같은 GitHub Pages 의 `/partner/` 아래에 올라갑니다.
- 화면: 소개, 의뢰 만들기(앱 카드 미리보기·예상 비용), 내 의뢰, 활동 리포트(인쇄·PDF 저장)
- 데이터: `src/api.js` 한 파일에 서버 구현과 시연용 구현이 같이 있습니다. 호출 이름은 `docs/api.md` 의 "제휴업체 웹"과 맞춥니다.
- 수수료, 문구, 예시 의뢰는 모두 임시입니다.
