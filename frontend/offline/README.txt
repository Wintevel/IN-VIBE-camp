집게표 전시 시연판 (인터넷 없이 실행)

[실행]
1. zip 파일을 오른쪽 클릭 > "압축 풀기"(모두 압축 풀기)로 먼저 풀어 주세요. zip 안에서 바로 실행하면 안 됩니다.
2. 풀린 폴더의 START.bat 을 더블클릭하세요.
   - "Windows의 PC 보호" 파란 창이 뜨면 "추가 정보" > "실행"을 누르세요.
3. 검은 창이 뜨고 브라우저(크롬·엣지)에 앱이 열립니다. 주소: http://localhost:8723/IN-VIBE-camp/
   - 브라우저가 안 열리면 위 주소를 직접 입력하세요.
   - 시연하는 동안 검은 창은 닫지 마세요. 닫으면 앱이 꺼집니다(최소화는 괜찮아요).
4. 전체 화면은 F11 입니다.

[시연판에서 달라지는 점]
- 서버(Supabase)에 연결하지 않고 이 PC 브라우저 안에 기록이 저장됩니다. 로그인·가입 없이 "시작하기"로 바로 들어갑니다.
- 내 위치는 인하대 근처로 고정됩니다(위치 권한을 묻지 않음).
- 의뢰판의 이웃 제보 6개와 크루 3개는 시연용 예시입니다. 시작 포인트 200점이 들어 있어 꾸미기 상점을 바로 써 볼 수 있어요.
- 사진: PC 에 카메라가 있으면 카메라로 찍고, 없으면 촬영 화면의 "카메라 없이 시연용 사진으로 찍기"를 누르세요.
  치우기 전은 쓰레기 그림, 치운 뒤는 깨끗한 그림이 들어갑니다.
- 전·후 사진 최소 간격이 1분 대신 10초입니다. 하루 인증 3개, 하트 10개 상한은 그대로예요.
- 지도는 인터넷 지도 대신 격자 바탕 위에 의뢰 위치만 표시합니다.

[관람객이 바뀔 때 처음 상태로 되돌리기]
내 정보 > 설정 > 맨 아래 "이 기기의 기록 모두 지우기"를 두 번 누르세요. 다음에 "시작하기"를 누르면 예시 데이터가 다시 들어갑니다.
(하루 인증 3개를 다 쓴 경우에도 이렇게 초기화하면 됩니다.)

[안 될 때]
- 검은 창에 "포트를 모두 쓸 수 없어요"가 나오면 PC 를 다시 켜고 START.bat 을 다시 실행하세요.
- 백신이 jipgepyo-server.exe 를 막으면 START.bat 이 자동으로 PowerShell 서버로 넘어갑니다.
- 그래도 안 되면 이 폴더에서 PowerShell 을 열고 다음을 실행하세요:
  powershell -ExecutionPolicy Bypass -File server\server.ps1
